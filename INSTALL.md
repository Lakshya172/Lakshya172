# Lakshya172 GitHub Profile README

## Install
1. Open the `Lakshya172/Lakshya172` repository (the repository name must match your GitHub username).
2. Upload `README.md` to the repository root, replacing the current profile README.
3. Upload the complete `assets/` directory to the same repository root.
4. Commit both the README and assets together.
5. Check the profile in both GitHub light and dark themes.

The README points to assets at:
`https://raw.githubusercontent.com/Lakshya172/Lakshya172/main/assets/`

If your default branch is not `main`, change `/main/` in the image URLs to your branch name.
