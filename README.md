### **ASTRA**

[Automated Stellar Transient Recognition & Analysis](https://github.com/Rexy-5097/ASTRA)

An end-to-end machine learning and research platform for automatically classifying stellar variability using TESS light curves.

**Python · PyTorch · CNN · Transformers · Next.js · ONNX**

- Built around machine learning models for classifying stellar variability into multiple astrophysical categories.
- Uses a Hybrid CNN + Transformer architecture to process raw and phase-folded light curves.
- Includes data acquisition, preprocessing, model training, evaluation, calibration, and uncertainty analysis.
- Supports reproducible research through dataset verification and hash-based integrity checks.
- Includes a web platform for interactive model inference and deployment.

<br/>

### **AdityaNet**

[GitHub Repository](https://github.com/Rexy-5097/AdityaNet)

A research platform focused on the Aditya-L1 solar X-ray archive and reproducible solar flare detection and analysis.

**Python · Data Analysis · Machine Learning · Scientific Computing**

- Works with scientific data from the Aditya-L1 SoLEXS and HEL1OS solar X-ray archive.
- Focuses on verifiable datasets, validation history, and reproducible research workflows.
- Includes data analysis and benchmarking for solar flare detection.
- Designed with an emphasis on scientific reproducibility and data integrity.
